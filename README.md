# SkillForge Academy — Online Course Website

A responsive online learning webpage built with **HTML5**, **CSS3**, and **JavaScript** featuring course categories, course cards, course information, instructor profiles, student reviews, and an enrollment section.

## Files Included
- `index.html`: Main webpage layout and sections.
- `style.css`: Responsive styles, layout grid, cards, and typography.
- `script.js`: Category filtering, mobile menu toggle, course selection pre-fill, and enrollment form feedback.
- `README.md`: Project overview.

## How to Run
Open `index.html` in any web browser or upload all files to GitHub Pages.
